# python-api-scripts

Scripts I wrote while learning how to work with REST APIs in Python. Started with free public APIs to understand how HTTP requests work before moving on to real projects.

## Scripts

### Weather
- `weather.py` - current weather for any city using OpenWeatherMap
- `forecast.py` - 5 day forecast

### JSONPlaceholder (fake REST API for practice)
- `crud_practice.py` - GET, POST, PUT, DELETE examples
- `users_comments.py` - working with nested resources

### Utils
- `helpers.py` - reusable functions for checking responses

## Setup

```bash
pip install -r requirements.txt
```

For weather scripts you need a free API key from openweathermap.org, put it in the `API_KEY` variable.

## What I learned

- How to make GET, POST, PUT, DELETE requests with Python requests library
- How to read JSON responses
- How to pass query parameters and headers
- Checking status codes and response time
